# Personal Portfolio — React SPA

Website portfolio pribadi yang dibangun menggunakan React sebagai Single Page Application (SPA). Project ini menggunakan React Router untuk navigasi halaman, Bootstrap dan CSS manual untuk styling, serta Vitest dan React Testing Library untuk pengujian.

## 🚀 Teknologi yang Digunakan

- React
- React Router DOM
- Bootstrap 5
- CSS3
- JavaScript
- Vite
- Vitest
- React Testing Library

## 📋 Fitur

- Home: Menampilkan profil singkat dan informasi utama.
- About: Menampilkan informasi diri dan keterampilan menggunakan CSS manual.
- Projects: Menampilkan daftar project yang pernah dibuat.
- Contact: Formulir kontak dengan validasi JavaScript.
- Responsive Design: Tampilan menyesuaikan berbagai ukuran layar.
- Dark Mode: Pilihan tampilan gelap.
- Reusable Navbar: Navigasi yang digunakan pada seluruh halaman dengan indikator halaman aktif.
- Lazy Loading: Memuat gambar secara bertahap untuk membantu optimasi performa.
